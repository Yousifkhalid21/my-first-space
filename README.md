# FigaroLabs Networking Studio

A bilingual Next.js + Tailwind CSS dashboard showcasing an interactive mind map for "Introduction to Computer Networking".

## Quick start

```bash
npm install
npm run dev
```

## Highlights

- Interactive SVG mind map with expand/collapse, focus, and search.
- Arabic (RTL) and English language toggle.
- Subscription-ready dashboard layout with pricing cards and analytics panels.
